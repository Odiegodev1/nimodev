SOBRE O PROJETO

Uma ideia pequena.
Um aprendizado gigante.

O NIMO /dev é um projeto acadêmico experimental que explora a integração entre sistemas embarcados, interfaces gráficas e aplicações web.

O objetivo é aprender construindo: desenvolver um produto físico, programar o firmware, consumir dados de uma API e criar uma experiência de interação agradável — tudo em uma pequena tela.

O protótipo continua em evolução. Novas funções e integrações podem ser exploradas nas próximas etapas do desenvolvimento.
